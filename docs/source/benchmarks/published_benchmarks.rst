Published benchmark data
========================

The evolving manuscript companion dataset uses concept DOI
`10.5281/zenodo.20305840 <https://doi.org/10.5281/zenodo.20305840>`_. Cite a
version-specific DOI for exact results.

The full-length extension at
`record 20687741 <https://doi.org/10.5281/zenodo.20687741>`_ contains uncapped
mouse and worm embedding/lookup runs, timings, missing-embedding reports, and
leakage-control outputs. Historical capped runs remain in the deposit history.
These are result archives, not reference databases.
