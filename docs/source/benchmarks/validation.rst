Validation scope and limitations
================================

FANTASIA transfers experimentally supported GO annotations from embedding
neighbours. Taxonomy and identity controls can test sensitivity to donor
availability, and cross-model semantic comparisons can describe concordance.
These analyses do not create an independent correctness gold standard.

Report coverage, failures, filters, donor changes, GO changes, and semantic
agreement separately. Alternative donors can transfer related GO terms, so
exact donor disagreement is not equivalent to functional disagreement.
