Choose Full FANTASIA or FANTASIA-Lite
=====================================

Use **Full FANTASIA** when you need the five supported embedding models,
database-backed references, taxonomy filtering, detailed donor rows, alignment
metrics, or proteome-scale operational workflows. Full requires PostgreSQL with
pgvector, RabbitMQ, reference-data restoration, and substantial model/storage
resources.

Use `FANTASIA-Lite <https://github.com/CBBIO/FANTASIA-Lite>`_ when you need a
standalone local workflow without database services. Lite is the more suitable
entry point for laptops, teaching, and small demonstrations.

The projects use different execution and output workflows. Follow the
documentation belonging to the selected repository.
