Computational benchmarks
========================

Benchmark timings are not runtime guarantees. They depend on software release,
reference release, model/cache state, hardware, sequence lengths, enabled
exports, and whether embeddings are reused. Published timing tables and raw
runs belong in versioned benchmark deposits, accompanied by the full
environment and configuration.

The repository contains scripts and recorded summaries under ``tests/`` for
annotation and full-length mouse/worm workflows. Treat those records as
release-validation evidence, not universal performance expectations.
